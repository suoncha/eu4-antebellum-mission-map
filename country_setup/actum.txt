# Tags with an Ante Bellum: Actum mission tree. They are highlighted in the Actum map mode, and the
# country panel shows their Actum tree.
#
# Same syntax as ab.txt. One tag per line; the script finds the tag's tree by itself in the Actum mission
# files (AB_*.txt with the submod's versions winning, plus every file in the submod's missions folder).
# To choose the files yourself, write them after "=", e.g.:   LIT = AB_Baltic_LIT.txt
# Switchable trees (formables, alternatives) are separated by "|", each written as "Label: files".
# "+flag" / "-flag" after the files assume that country flag (or modifier, or government attribute) set / unset for the tree, e.g.
#   WAL = ABMP_WAL.txt +wal_unlocked_timed     (drops the locked placeholder series)
#   ">TAG >TAG" after the files shows the tree as if the country had formed those tags in turn (every stage
#   unlocked, no Form button), e.g.   ATG = AB_Anatolia_RUM_Christian.txt >RUM >ROM
#   "none" = no tree; a label TAG "Name" shows as "Form Name", e.g.   GAL = none | VSG "Suebi": TLW_Iberian_VSG.txt >VSG
# "found:" comments show what the script detected when this file was generated. Lines starting with
# # are ignored.
